練習19（教科書 p.148）

c ＝ 10 である △ABC において，外接円の半径が R ＝ 10 のとき，C を求めよ。

ヒントは 3 個あります

ヒント1：正弦定理の「＝ 2R」の部分を使う。辺 c と，その向かいの角 C がペア。
ヒント2：csin C ＝ 2R に c ＝ 10，R ＝ 10 を代入して，sin C の値を出す。
ヒント3：sin C の値が決まっても，0° ＜ C ＜ 180° の範囲では，鋭角と鈍角の2つの角がありうる。
答え：C ＝ 30°，150°
詳解：正弦定理により csin C ＝ 2R である。c ＝ 10，R ＝ 10 を代入すると 10sin C ＝ 20 となるから，sin C ＝ 1020 ＝ 12。0° ＜ C ＜ 180° であるから，C ＝ 30°，150°。

類題教科書には載っていない類題

b ＝ 5√2 である △ABC において，外接円の半径が R ＝ 5 のとき，B を求めよ。

ヒントは 2 個あります

ヒント1：ペアは，辺 b と角 B。使う式は bsin B ＝ 2R。
ヒント2：sin B ＝ b2R の形にして値を出す。
答え：B ＝ 45°，135°
詳解：正弦定理により bsin B ＝ 2R である。b ＝ 5√2，R ＝ 5 を代入すると，sin B ＝ 5√210 ＝ √22。0° ＜ B ＜ 180° であるから，B ＝ 45°，135°。
