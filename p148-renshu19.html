練習19（教科書 p.148）

△ABC において，次のものを求めよ。
(1) b ＝ 6，B ＝ 30°，C ＝ 45° のとき c(2) c ＝ 4，A ＝ 120°，B ＝ 15° のとき a

ヒントは 3 個あります

ヒント1：求める辺の向かいの角がまだわからないときは，先に三角形の内角の和（180°）から残りの角を求める。
ヒント2：正弦定理は「辺と，その向かいの角」のペアで使う。(1) は c と C，b と B のペア。(2) は a と A，c と C のペア。
ヒント3：(2) では sin120° が必要になる。sin120° ＝ sin(180° − 120°) ＝ sin60° と直してから計算する。
答え：(1) c ＝ 6√2　(2) a ＝ 2√6
詳解：(1) A ＝ 180° − (30° ＋ 45°) ＝ 105°。正弦定理により csin C ＝ bsin B であるから，csin 45° ＝ 6sin 30°。よって c ＝ 6・sin 45°sin 30° ＝ 6・√2/21/2 ＝ 6√2。(2) C ＝ 180° − (120° ＋ 15°) ＝ 45°。正弦定理により asin A ＝ csin C であるから，asin 120° ＝ 4sin 45°。sin120° ＝ sin60° ＝ √32 だから，a ＝ 4・sin 120°sin 45° ＝ 4・√3/2√2/2 ＝ 2√6。

類題教科書には載っていない類題

△ABC において，c ＝ 6，C ＝ 90°，A ＝ 30° のとき，a と b を求めよ。

ヒントは 2 個あります

ヒント1：直角三角形でも正弦定理はそのまま使える。sin90° ＝ 1 がポイント。
ヒント2：a は A と，b は B とペアにする。B は内角の和から先に出す。
答え：a ＝ 3，b ＝ 3√3
詳解：B ＝ 180° − (90° ＋ 30°) ＝ 60°。正弦定理により asin A ＝ bsin B ＝ csin C であるから，a ＝ 6・sin 30°sin 90° ＝ 6・12 ＝ 3，b ＝ 6・sin 60°sin 90° ＝ 6・√32 ＝ 3√3。
